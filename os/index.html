Two prompts worth keeping

Copy either one and paste it into a new chat. The first goes on top of everything you ask. The second finds the work worth automating.

Save it once

Make a text shortcut so typing ;mp pastes the master prompt. Text shortcuts handle line breaks badly, so use the one-paragraph version above.

  • Mac: System Settings → Keyboard → Text Replacements → +. Replace: ;mp. With: the paragraph. Click Add.
  • iPhone: Settings → General → Keyboard → Text Replacement → +. Phrase: the paragraph. Shortcut: ;mp. Save. If you set it up on your Mac first, iCloud syncs it.
  • Test it: open Notes, type ;mp and press space.
