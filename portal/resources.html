How to add a skill

Seven short steps. Leave the file as a ZIP the whole way through.

  1. 01

    Download the ZIP

    Use Download on the skill card. The file saves to your computer.

  2. 02

    Keep it zipped

    Leave the skill as a ZIP. Uploading an unzipped folder will not work.

  3. 03

    Open Skills

    In your AI tool, open the screen where you add Skills.

  4. 04

    Click Upload

    Choose Upload on that screen.

  5. 05

    Select the ZIP

    Pick the file you just downloaded. Do not rename it.

  6. 06

    Confirm and save

    Accept the prompt so the skill is stored on your account.

  7. 07

    Start using it

    Open a new chat. The skill is ready.
