Time Rich Accelerator — plain HTML version
==========================================

Files
  index.html   the whole page (all text, links and sections)
  styles.css   all colours, fonts and layout
  script.js    menu, FAQ, video window, counters, countdown, floating join bar
  assets/      photos, logos and the overview video

To view: double-click index.html, or upload the whole folder to any web host.

Common edits
  - Join link: search index.html for "https://timerich.ai/join/" and replace it.
  - Cohort start date (countdown): change COHORT_START at the top of script.js.
  - Text and prices: edit them directly in index.html.
